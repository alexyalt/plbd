# plbd

Система учёта защиты зелёных насаждений: осмотры, обработки, расход препаратов.

Статус: этап 0 (анализ и ТЗ). Рабочего приложения пока нет.

- `docs/ANALYSIS.md` — анализ старых баз Access
- `docs/TZ.md` — техническое задание
- `docs/legacy/vba_source.txt` — извлечённый VBA-код старой системы
- `workbook.md` — журнал работ
- `AGENTS.md` — правила разработки

Старые файлы `.accdb` и шаблоны `.xltx` лежат в корне и не изменяются.
